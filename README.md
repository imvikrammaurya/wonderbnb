# Wonderbnb 🏨

A full-stack vacation-rental marketplace inspired by **Airbnb**.  
Users can browse, search, and book amazing stays worldwide — and even list their own properties!

## 🚀 Features

### 🏠 Listings & Properties
- Browse accommodations with images, pricing & location details
- Filter listings by categories: Trending, Iconic Cities, Mountains, Castles, Pools, Camping, etc.
- Search by **Location**, **Dates**, and **Guests**
- Interactive map to view listing locations *(if implemented)*
- **GST Toggle** – Show total price including **18% tax**

### 📝 Booking & Reservations
- Real-time **dynamic pricing**
  - Weekend surge pricing
  - Extra charges for additional guests
- Litepicker for date selection
- Reservation + Payment flow for bookings

### ❤️ Wishlist & Sharing
- Save listings to personal wishlist
- One-click **Share** button copying URL to clipboard

### 👤 User Management
- Secure Login / Signup with Authentication
- Host dashboard to **Add / Edit / Delete** properties
- Star Ratings + Review comments on listings

### 🎨 UI / UX Highlights
- Fully responsive using **Bootstrap 5**
- **Off-Canvas Sidebar** for advanced filters
- Sticky navigation for easy access

## 🛠️ Tech Stack

### Frontend
- HTML5, CSS3
- Bootstrap 5
- EJS Templating
- Client-side JavaScript (Litepicker, DOM)

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Atlas)
- Mongoose ODM

### Other Tools & Libraries
- Passport.js (Authentication)
- Cloudinary (Image Uploads)
- Joi (Validation)
- Connect-Flash (Flash messages)
